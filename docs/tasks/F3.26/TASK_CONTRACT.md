# F3.26 Inline table editor contrast

## Scope

Correct the low-contrast text shown by the native inline input used when a
table cell is edited with double-click.

## Acceptance

- Text and caret in the inline editor remain clearly visible on the white cell
  background in the application's dark theme.
- Enter, blur, and Escape behavior remain unchanged.
- The change does not alter table tokens, SVG metadata, print behavior, or
  deployment configuration.
