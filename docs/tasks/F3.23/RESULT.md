Limits: This is a local loopback pilot, not a company-server production deployment. The application process on 8765 is not configured as an OS service, so it must be started again after a Windows reboot. The local pilot currently uses MinIO root credentials for application access; replace them with least-privilege service credentials and TLS before any shared/server rollout. The artifact adapter has a check-then-put race under concurrent writers with the same payload reference, so cross-process immutability is not yet proven. Existing nested SVG migration needs `.folder` marker support before use on a populated source library; the current source has no custom SVG templates. Full backend suite, browser-authenticated end-to-end test, SAP, printer, Jenkins, and production database were not run. No source files were deleted, and no commit/push/PR was made.
