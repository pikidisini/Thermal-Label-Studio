# Thermal Label Studio

Vocabulary for the operational boundary between the application, SAP, and label-output devices.

## Release scope

**Internal LAN application release**:
An HTTPS-served application release for authenticated internal users to manage templates and data, and to preview or simulate labels. SAP RFC execution and physical-printer delivery remain disabled and are accepted separately.
_Avoid_: full production, SAP go-live, printer go-live
